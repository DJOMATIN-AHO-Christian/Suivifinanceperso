# Suivi Finance Perso · Dashboard Patrimonial & Budgétaire

Dashboard financier complet, interactif et minimaliste sous forme de fichier autonome, avec intégration Google Sheets, gestion multi-devises et analyse de patrimoine.

## Fonctionnalités

- **Score de Santé Financière (0-100)** : Évaluation dynamique basée sur 6 piliers (taux d'épargne, fonds de sécurité, endettement, diversification, objectifs, discipline).
- **Budget Base Zéro & 4 Enveloppes** : Fixe Essentiel, Variable / Qualité de vie, Futur (Épargne & Investissement), Non Alloué.
- **Strates de Dépenses (N1 à N4)** : Du vital (Survie N1) au superflu (Luxe N4) pour prioriser les arbitrages.
- **Épargne de Précaution** : Structure en 3 paliers (Urgence 48h, Sérénité 1-3 mois, Forteresse 3-6 mois).
- **Simulations d'Investissement** : DCA, Intérêts composés et simulation stochastique Monte Carlo (150 scénarios).
- **Indépendance Financière (FIRE)** : Calcul du nombre FIRE, Lean FIRE et Fat FIRE.
- **Gestion Multi-Devises Réelle** : Conversion dynamique entre EUR, USD, FCFA, GBP et CHF.
- **Connexion Google Sheets** : Synchronisation avec un script Google Apps Script pour l'historique et les snapshots mensuels.
- **Design Minimaliste** : Thème sombre et clair, curseurs ergonomiques, typographies modernes (Inter / Poppins), sans emojis.

## Fichiers

- `ÉTAT DES LIEUX COMPLET.html` : L'application web complète (HTML, CSS et JavaScript vanilla).
- `google-apps-script.js` : Le script backend pour Google Sheets / Google Apps Script.
